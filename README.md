# Diablo-MS-Lexicon

《暗黑破坏神 IV》+《暗黑破坏神 II：重生》**微软拼音「用户自定义短语」**词库（按中文词语去重合并）。

打游戏聊天、看攻略时，直接输入拼音即可优先打出：`地狱潮汐`、`传奇威能`、`恐怖地带`、`符文之语`、`乔丹之石` 等系统词库常缺的专有名词。

> 许可证：**MIT**（见 `LICENSE`）。游戏专有名词的商标与版权归暴雪 / Blizzard 所有；本仓库仅提供玩家常用中文译名与俗称的输入法短语整理，不包含游戏资源文件。

---

## 可导入文件

| 文件 | 用途 |
|------|------|
| **`diablo-microsoft-pinyin.dat`** | **推荐**：D4+D2R 合并包，设置里「导入」 |
| `d4.dat` / `d2r.dat` | 只导入暗黑四或只导入暗黑二重生 |
| `diablo-microsoft-pinyin.txt` | UTF-8；给 [PinyinLexTool](https://github.com/mchudie/PinyinLexTool) 用 |
| `d4.txt` / `d2r.txt` | 分游戏 TXT |
| `diablo-microsoft-pinyin-utf8bom.txt` | 同上，带 UTF-8 BOM |

TXT 行格式：`拼音<TAB>候选位置<TAB>词语`

合并规则：同一中文词语只保留一条（D4 优先，再追加 D2R 独有词）；同一拼音下不同词语占用候选位 1–9。

## 更新时怎么导入（避免重复）

微软拼音自定义短语导入多为**追加/合并**，同一整合包叠导可能重复。**建议：先清除之前导入的游戏短语，再导入新的整合包。**

1. 设置 → … → 微软拼音 → 词库和自学习 → **自定义短语**
2. （可选）先**导出**备份
3. 删掉旧的游戏相关短语，或清空后只保留你自己的短语
4. **导入**新的 `.dat` 整合包

---
## 导入步骤（Win10 / Win11）

1. **设置** → **时间和语言** → **语言和区域**
2. 中文（简体）→ **选项** → **微软拼音** → **选项**
3. **词库和自学习** → **添加或编辑自定义短语** → **导入**
4. 选择本仓库的 `diablo-microsoft-pinyin.dat`
5. 切换一下输入法使短语生效；测试输入 `helltide` / `kongbudidai` 等

导入前建议先导出备份自己的自定义短语。

## 格式要点

- 文件头魔法字：`mschxudp`
- 拼音与词语在 `.dat` 内为 **UTF-16 LE**
- 拼音 ≤32、不以 `u`/`v` 开头、仅 `a-z`；词语 ≤64；候选位 1–9

## 本地重新构建

```bash
python3 -m venv .venv
.venv/bin/pip install pypinyin
.venv/bin/python build.py
```

词表源码：`source/d4_words.py`、`source/d2r_words.py`  
`.dat` 构建逻辑基于 [youmuyou/mschxudp](https://github.com/youmuyou/mschxudp)（`tools/`）。

## 来源与原则

- 国服/社区常用译名与俗称（D2R 参考社区通行称呼与简中对照，不编造）
- 极生僻 lore 长句不收录
- 拼音默认无调连续全拼；部分俗称带易记触发码（如 `soj`→乔丹之石、`spirit`→精神）
