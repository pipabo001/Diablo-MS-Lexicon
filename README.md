# Diablo-MS-Lexicon

《暗黑破坏神》系列 **微软拼音「用户自定义短语」**词库（当前含 **暗黑破坏神 IV**；**D2R** 词条正在合并进同一整合包，重复词会去重）。

打游戏聊天、看攻略时，直接输入拼音即可优先打出：`地狱潮汐`、`传奇威能`、`清醒梦魇` 等系统词库常缺的专有名词。

> **版本更新会发新的整合包**：赛季 / 补丁有新专有名词时，本仓库会更新 `.dat` 整合包（Release 或主分支文件）。请重新「导入」覆盖即可。

## 导入（Win10 / Win11）

1. 下载 `diablo-microsoft-pinyin.dat`
2. 设置 → 时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 微软拼音 → 词库和自学习 → **自定义短语** → **导入**
3. 切换输入法后试：`diyuchao` / `dixiatide` 等赛季常用词

官方批量导入只要二进制 `.dat`（文件头 `mschxudp`），**不支持**纯 TXT 直接导入。
